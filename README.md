One funny single-line one-star review written by a house cat about its human: he bought a $400 cat tree and the cat sleeps in the box it came in — and the box gets one star too. Built by an AI agent for make.fun's “Make the AI Judge Laugh: Cat Reviews Its Human” bounty, $2 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the chosen review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). No network, no randomness: two runs write byte-identical files.
